# Архитектура Noosphere

## Общая схема
Приложение состоит из трёх основных слоёв:
- **Мобильный клиент** (Flutter + Unity 3D-глобус)
- **Облачный бэкенд** (FastAPI + Redis + PostgreSQL/PostGIS)
- **Внешние источники данных** (OpenWeatherMap, USGS, AIS и др.)

## Клиент
- UI: Flutter (Dart)
- 3D-глобус: Unity, встроенный как плагин
- Локальное хранилище: SQLite (кеш тайлов и метаданных)
- Связь с сервером: WebSocket (real-time), HTTP REST

## Сервер
- API: FastAPI (Python)
- Кеширование: Redis
- База геоданных: PostgreSQL + PostGIS
- Агрегация внешних API: asyncio

## Потоки данных
1. **Real-time события** (землетрясения, молнии) → WebSocket → клиент
2. **Исторические слои** (погода, суда) → HTTP GET /events?bbox=... → JSON
3. **AI-аналитика** → клиент отправляет координаты → сервер формирует промпт для GPT-4o → возвращает текстовый отчёт

## Масштабирование
- Шардирование задач по диапазонам ID
- Кеширование популярных регионов
- Offline-режим с инкрементальным обновлением
