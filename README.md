# Noosphere – Цифровой двойник планеты

Приложение, которое в реальном времени показывает события на Земле (землетрясения, суда, погоду) и позволяет получить AI-аналитику по любой точке мира.

## Возможности
- 3D-глобус с вращением и масштабированием
- Слои данных: температура, осадки, пожары, морские суда, самолёты, сейсмическая активность
- AI-отчёт по выбранной области (климат, риски, население)
- Оффлайн-режим для загруженных регионов
- Real-time уведомления о важных событиях

## Технологии
- Flutter + Unity (3D-движок)
- FastAPI, Redis, PostgreSQL/PostGIS
- Интеграция с открытыми API (OpenWeatherMap, NASA GIBS, USGS и др.)

## Статус
Проект в активной разработке. Первая цель: запустить сервер-агрегатор данных и визуализировать прототип глобуса.## Работающий прототип API
Сервер возвращает тестовые события (землетрясения, молнии, пожары):
- Главная: [noosphere-6n6y.onrender.com](https://noosphere-6n6y.onrender.com)
- События: [noosphere-6n6y.onrender.com/events](https://noosphere-6n6y.onrender.com/events)
