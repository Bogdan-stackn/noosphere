# Как помочь проекту Noosphere

Привет! Я разрабатываю Noosphere в одиночку, но буду рад любой помощи.

## Сообщить об ошибке
1. Проверьте [Issues](https://github.com/твой_логин/noosphere/issues).
2. Создайте новый Issue, описав устройство, шаги и ожидаемое поведение.

## Предложить идею
- Создайте Issue с меткой `enhancement`.

## Внести код (Pull Request)
1. Сделайте Fork репозитория.
2. Создайте ветку (`feature/...`).
3. Внесите изменения.
4. Отправьте Pull Request.

Перед отправкой большого PR, пожалуйста, откройте Issue для обсуждения.

## Стиль кода
- Читаемость и комментарии приветствуются.
- Язык: русский или английский.
